# Security Policy

## How to report a vulnerability

If you believe you have found a security vulnerability in iBoysoft NTFS for Mac, please report it privately. Do not open a public GitHub issue.

- Email: [support@iboysoft.com](mailto:support@iboysoft.com) (Monday–Friday, 9:00–18:00, UTC+8)
- Or use [GitHub private vulnerability reporting](https://github.com/iBoysoft/iBoysoft-NTFS-for-Mac/security/advisories/new)

Include a clear description of the issue, affected versions if known, and steps or proof-of-concept details that help us reproduce it.
